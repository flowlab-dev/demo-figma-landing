# QuirvaleTravel: a Figma landing page coded in HTML and CSS (demo)

A self-initiated demo by Flow Lab, not a paid client project. QuirvaleTravel is an invented travel brand. The layout is the free Figma Community file "Travel Landing Page DESKTOP + MOBILE (FREE)" by Kunturi Design (CC BY 4.0), coded by hand to match it at desktop and phone sizes. It is a demo on made-up data.

- Live demo: https://flowlab-dev.github.io/demo/figma-landing/
- Case study: https://flowlab-dev.github.io/work/figma-landing/

Built by Flow Lab with Claude Code. The page was checked at 9 screen widths from 390 to 1512 px and compared with the design pixel by pixel: 5.4% of pixels differ at 1512 px and 9.3% at 390 px.

## What's inside

- `index.html`, `styles.css`, `main.js`: the page, no framework and no build step.
- `img/`: photos and icons; every source and license is listed in `img/CREDITS.txt`.

Open `index.html` in a browser.
